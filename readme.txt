超台本　「ヒ・ト・ミ」 ver2.0 - TyranoScript版

OS：Windows、macOS、Linux対応（ブラウザで動作）
ブラウザ：Chrome、Firefox、Safari、Edge等の現代的なブラウザ
JavaScript：有効化必須
画面解像度：1024×768以上推奨

原作者：okajun
原作ツール：吉里吉里2/KAG3
移植版ツール：TyranoScript

■はじめに
　このたびは、本作品を手に取っていただき、誠にありがとうございます。
本作品は劇団InnocentSphereが2009年に公演された「ヒ・ト・ミ」の台本と公演の写真を
もとに構成されました。

この版は、オリジナルの吉里吉里版からTyranoScriptに移植されたバージョンです。
ブラウザ上で動作するため、より多くの環境でお楽しみいただけます。
エンディングまでのお付き合いいただき、もしInnocentSphereの舞台にご興味がわきましたら、
劇場まで足をお運びいただき、生の舞台を体感してみてください。

■インストール・起動方法
TyranoScript版は展開後、「index.html」をブラウザで開いてください。
ローカルファイルとして実行できますが、Webサーバー上に配置することも可能です。

■アンインストール
TyranoScript版はフォルダごと削除するだけで完全にアンインストールできます。
ブラウザの一時ファイルやキャッシュは、ブラウザの設定から削除してください。

■システム
基本的にマウスクリック、またはエンターキーで読み進めていくだけです。
ブラウザの機能により、ゲーム画面のサイズ調整なども可能です。
